

Our project focuses on analysing histopathology images using deep learning.

Histopathology images are images of body tissues examined under a microscope. Studying these images helps researchers understand tissue structures and identify abnormal patterns.

In this project, we have developed an application where users can upload histopathology images and process them through our image analysis system.

The main aim is to explore how deep learning and image processing can assist in analysing tissue images.

This project is an academic prototype developed for learning and research purposes. It is not intended to provide medical diagnoses.
